Your workspace and connected services

Hive runs coding agents in an environment on a computer you choose. That host stores thread history, settings, drafts, and related workspace records. Your browser or app can also save preferences, drafts, and cached display data on its own device. If you connect another device or a remote environment, information travels between those devices and the selected host. I do not operate a Hive relay.

When you send a prompt, the coding agent and its configured AI services can receive the prompt, conversation context, attachments, files, and tool results used for that work. Some Hive features also send context to a configured AI service to generate text such as a title, branch name, recap, or pull request description. The destination can depend on your settings and available providers. Hive 5.0.0 can send an issue draft to an AI service for automatic naming. Review your agent, model, and text-generation settings before using work information.

You and your organization decide what to connect and which content to submit. The providers you choose handle information under their own agreements and settings. Their retention, training, and international-processing practices can vary by account, plan, model, endpoint, and feature.

  • OpenCode’s Privacy Policy explains its website, model gateway, and hosted-service processing.
  • Codex plan and data controls explains how data use depends on your OpenAI account and settings.
  • GitHub Copilot account policies explain personal-account controls, including model training.

Connecting Linear

Connecting Linear authorizes Hive to request workspace information from Linear’s hosted MCP service. Hive initially requests read access. Issue editing requires an additional read-and-write authorization. Depending on what you open, Hive can retrieve workspace and team information, issue titles and descriptions, assignees and other people, comments, projects, milestones, and documents. Supported edits and comments are sent back to Linear when you use those actions.

Hive saves the connection’s access and refresh credentials in a restricted directory on your host. Selected Linear views can be cached in the client’s browser storage. The current display cache uses a 15-minute freshness limit. An inactive client can retain stale entries until it next accesses the cache or you clear its stored data.

Linking an issue saves its workspace identifier, issue key, and URL with the Hive thread. Choosing to start work from an issue can copy its key, title, link, and available description into an editable draft. You can review and remove information before sending. Sending shares the remaining draft with the coding agent and its configured AI services. Hive versions and naming settings can affect what is sent for automatic naming.

Disconnecting an established connection removes Hive’s saved credential. You can also revoke the grant in Linear under Settings → Security & Access → Authorized applications. Previously saved issue links can reappear after reconnection. Messages, agent sessions, exports, backups, and edits already made in Linear have their own deletion controls and retention rules.

Read Linear’s Privacy Policy and Terms of Service for Linear’s processing. The same need to review a service’s permissions and terms applies when you configure another MCP server or integration.

This website, downloads, and support

This website is hosted on Cloudflare Pages. Visiting it sends ordinary request information, such as your IP address, requested URL, browser information, and request time, to the hosting service to deliver and protect the site. The site code includes no advertising or analytics trackers. Cloudflare handles hosting and security information under its Privacy Policy.

The home page requests the public release manifest from GitHub Pages to show the latest download. Downloads, update checks, releases, issues, and discussions use GitHub services. Those requests disclose network information to GitHub. Information you post in the public issue tracker or discussions is visible publicly. See GitHub’s Privacy Statement.

If you email support, I receive your message and any attachments in my Gmail mailbox. If you report a problem through GitHub, I can read what you post there. This can include your name, email address, messages, logs, screenshots, or files. Review those materials and remove credentials or unrelated personal information before sharing them. For a private security report, email me directly instead of opening a public issue.

External product telemetry is off by default in current Hive builds. Optional diagnostics can send information to a receiver you or your administrator configures. Error messages and traces can include details of the operation being handled. Check the destination and its access rules when enabling exports.
